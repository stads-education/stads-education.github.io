Session 2: Python Basics II

Daten sammeln, wiederholen und wiederverwenden.

In dieser Session lernst du die vier Sammlungstypen von Python kennen, wiederholst Code mit Schleifen und packst Logik in eigene Funktionen, damit du sie nicht immer wieder neu schreiben musst.


Themen

Python Lists

Listen speichern mehrere Werte in einer Variable, geschrieben in eckigen Klammern. Sie sind geordnet, veränderbar und erlauben doppelte Werte. Der erste Eintrag hat den Index 0.

fruechte = ["Apfel", "Banane", "Kirsche"]
fruechte.append("Mango")
print(fruechte[0], len(fruechte))   # Apfel 4

Python Tuples

Tupel funktionieren ähnlich wie Listen, werden aber mit runden Klammern geschrieben und sind nicht veränderbar. Sie eignen sich für feste Daten wie Koordinaten. Ein Tupel mit nur einem Element braucht ein Komma: ("a",).

punkt = (49.48, 8.47)
print(punkt[0])     # 49.48
# punkt[0] = 50     → Fehler, Tupel sind unveränderbar

Python Sets

Sets stehen in geschweiften Klammern, sind ungeordnet und enthalten jeden Wert nur einmal. Doppelte Einträge werden automatisch entfernt. Ideal, wenn nur die eindeutigen Werte zählen.

farben = {"rot", "blau", "rot", "grün"}
print(farben)            # {'rot', 'blau', 'grün'}
farben.add("gelb")

Python Dictionaries

Dictionaries speichern Daten als Schlüssel-Wert-Paare. Über den Schlüssel greift man direkt auf den Wert zu. Jeder Schlüssel ist eindeutig, Werte können aber jeden Datentyp haben, auch Listen.

student = {"name": "Lea", "semester": 3, "kurse": ["Python", "SQL"]}
print(student["name"])       # Lea
student["semester"] = 4

Python While Loops

Eine while-Schleife wiederholt Code, solange eine Bedingung wahr ist. Wichtig: Die Bedingung muss irgendwann falsch werden, sonst läuft die Schleife endlos. Mit break bricht man vorzeitig ab, mit continue springt man zum nächsten Durchlauf.

i = 1
while i <= 3:
    print("Durchlauf", i)
    i += 1

Python For Loops

Eine for-Schleife geht jedes Element einer Sequenz durch, z. B. eine Liste, einen String oder ein Dictionary. Mit range() lässt sich auch einfach eine bestimmte Anzahl an Wiederholungen erzeugen.

for frucht in ["Apfel", "Banane"]:
    print(frucht)

for i in range(3):
    print(i)        # 0, 1, 2

Python Functions

Mit def definiert man eine Funktion: einen benannten Codeblock, den man beliebig oft aufrufen kann. Funktionen können Parameter entgegennehmen und mit return ein Ergebnis zurückgeben.

def begruessung(name):
    return "Hallo " + name + "!"

print(begruessung("Max"))   # Hallo Max!

Python Lambda

Eine Lambda-Funktion ist eine kleine, namenlose Funktion in einer Zeile: lambda argumente: ausdruck. Sie wird oft kurz zusammen mit sorted(), map() oder filter() genutzt.

verdoppeln = lambda x: x * 2
print(verdoppeln(5))        # 10

namen = ["Tom", "Alexandra", "Eva"]
print(sorted(namen, key=lambda n: len(n)))

Python Scope

Der Scope bestimmt, wo eine Variable sichtbar ist. Variablen innerhalb einer Funktion sind lokal und nur dort verfügbar. Variablen im Hauptprogramm sind global und überall lesbar.

x = 10              # global

def zeige():
    y = 5           # lokal
    print(x + y)

zeige()             # 15
# print(y)          → Fehler, y existiert nur in der Funktion
